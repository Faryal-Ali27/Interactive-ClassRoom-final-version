Quick actions

How it works

  1. Share the class. Students scan the QR code (it joins this room automatically) or type the room code.
  2. Ask a question. Pick a type, write it, choose a timer and send. Add an explanation if you want students to learn why.
  3. Watch live. Results, confused students and pace update on this screen.
  4. Close the loop. When time is up the correct answer and explanation appear on student phones. Reply to student questions in the Q&A tab.
  5. Many questions? Use the Queue tab, then Import to add a whole Word, CSV or text file at once.
